# Phase 30 Plan: Distributed Sensory Memory Graph & Cross-Modal Embeddings

## 1. Overview
Implement the distributed sensory memory graph engine connecting multi-modal artifacts, desk ledger events, and tool execution traces into an integrated property graph with cross-modal vector retrieval, temporal decay weighting, graph partitioning caching, and cryptographic state commitments.

## 2. Requirements Covered
- `REQ-GRAPH-001`: Knowledge graph linkage mapping multi-modal artifacts, desk ledger events, and tool execution traces into an integrated property graph.
- `REQ-GRAPH-002`: Cross-modal semantic search engine with cosine nearest-neighbor vector retrieval across heterogeneous embeddings.
- `REQ-GRAPH-003`: Temporal graph decay and attention weighting prioritizing recent and high-relevance nodes.
- `REQ-GRAPH-004`: Graph partitioning and edge-node caching for low-latency graph traversals.
- `REQ-GRAPH-005`: Cryptographic graph state commitment and Merkle verification receipts.

## 3. Implementation Tasks
1. Create `services/desk-gateway/src/desk_gateway/memory_graph.py`:
   - `GraphNode` & `GraphEdge` dataclasses with modal types (`TEXT`, `CODE`, `IMAGE`, `EVENT`, `TOOL_TRACE`), metadata, vector embeddings, timestamps, and attention scores.
   - `SensoryMemoryGraphEngine`:
     - Node & edge addition, indexing, and bidirectional graph linkage (`REQ-GRAPH-001`).
     - Cross-modal cosine semantic search with top-k ranking and similarity scoring (`REQ-GRAPH-002`).
     - Exponential temporal decay function with configurable half-life and attention weighting (`REQ-GRAPH-003`).
     - Partitioned subgraph traversal with LRU cache and depth limiting (`REQ-GRAPH-004`).
     - Incremental Merkle root computation over graph state with cryptographic verification receipts (`REQ-GRAPH-005`).
2. Expose endpoints in `services/desk-gateway/src/desk_gateway/server.py`:
   - `POST /v1/graph/node/create`
   - `POST /v1/graph/edge/create`
   - `POST /v1/graph/search/semantic`
   - `GET /v1/graph/traverse/{node_id}`
   - `POST /v1/graph/commit`
3. Comprehensive test suite in `services/desk-gateway/tests/test_memory_graph.py`.
4. Run CI gates (G-1, G-3, G-7).
