# Plan 27-01: Continuous Merkle Proof Verification & Immutable Audit Export

**Milestone:** v3.0 - Continuous Zero-Trust Compliance & Cryptographic Enclave Attestation  
**Phase:** 27 - Continuous Merkle Proof Verification & Immutable Audit Export  
**Requirements:** `REQ-ZERO-006`, `REQ-ZERO-007`, `REQ-ZERO-008`, `REQ-ZERO-009`, `REQ-ZERO-010`

## Goal
Implement a continuous incremental Merkle tree aggregator, audit consistency verifier, external anchor exporter, and automated tamper-detection scrubber in `desk-gateway`:
1. Continuous incremental Merkle tree aggregator over all desk operations (`REQ-ZERO-006`).
2. Cryptographic inclusion and consistency proof generator for arbitrary time windows (`REQ-ZERO-007`).
3. External immutable audit log export adapter supporting WORM/Solana devnet anchoring (`REQ-ZERO-008`).
4. Automated tamper-detection audit scrubber identifying manipulated log entries (`REQ-ZERO-009`).
5. End-to-end zero-trust compliance verification suite with signed attestation receipts (`REQ-ZERO-010`).

## Implementation Tasks
1. **Module `services/desk-gateway/src/desk_gateway/merkle_audit.py`**:
   - `AuditLeaf`: Dataclass capturing leaf index, timestamp, seat_id, operation, payload_digest, and leaf_hash.
   - `IncrementalMerkleTree`:
     - Append leaf digests to binary tree representation.
     - Compute and update Merkle root continuously.
     - Generate cryptographic inclusion proofs (sibling path hashes).
     - Verify inclusion proof against specific Merkle root.
   - `ImmutableAuditExporter`:
     - Format and export audit batches to external append-only WORM / Solana devnet anchor payloads.
     - Sign anchor export with non-repudiation signature.
   - `AuditLogScrubber`:
     - Scrub audit history to detect bit flips, missing entries, or tampered payload digests.
   - `ZeroTrustComplianceVerifier`:
     - Conduct end-to-end audit compliance drills and emit signed compliance receipts.
2. **Gateway Endpoints in `server.py`**:
   - `POST /v1/audit/merkle/append`: Append operation to continuous Merkle audit tree.
   - `GET /v1/audit/merkle/root`: Get current Merkle root and leaf count.
   - `POST /v1/audit/merkle/proof`: Generate inclusion proof for leaf index.
   - `POST /v1/audit/merkle/verify`: Verify an inclusion proof against root.
   - `POST /v1/audit/export/anchor`: Export anchor batch for external WORM/Solana anchoring.
   - `POST /v1/audit/scrub`: Run tamper-detection scrubber across audit entries.
   - `POST /v1/audit/compliance/drill`: Run full zero-trust compliance verification drill and get signed receipt.
3. **Tests & Verification**:
   - `services/desk-gateway/tests/test_merkle_audit.py`:
     - Leaf hashing and incremental tree root updates.
     - Cryptographic inclusion proof generation and verification.
     - Rejection of forged or tampered inclusion proofs.
     - WORM / Solana devnet anchor export payload formatting and signature.
     - Tamper scrubber detection of altered entries.
     - Compliance drill verification and HMAC signature check.
     - Starlette API routes via TestClient.
4. **Gates**:
   - G-1 through G-7 verified clean.
