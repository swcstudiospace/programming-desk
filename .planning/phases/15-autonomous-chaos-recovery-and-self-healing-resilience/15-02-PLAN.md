<objective>
Implement autonomous task graph rebalancing across healthy peer seats upon seat unresponsiveness, automated dead-letter queue (DLQ) replay orchestrator with exponential backoff, jitter, and poison payload quarantine, and a continuous resilience verification suite validating RPO=0 and RTO < 3s under simulated chaos (REQ-CHAOS-003, REQ-CHAOS-004, REQ-CHAOS-005).

Output:
- `desk_gateway.workload`: Autonomous task graph rebalancing algorithm (`WorkloadRebalancer`).
- `desk_gateway.dlq_replay`: Automated DLQ replay orchestrator with backoff & poison quarantine (`DLQReplayOrchestrator`).
- `desk_gateway.resilience`: Continuous resilience verification harness validating RPO=0 and RTO < 3.0s (`ResilienceVerifier`).
- REST endpoints in `desk_gateway.server` and verification test suite in `tests/test_resilience_recovery.py`.
</objective>

<tasks>
1. Implement `WorkloadRebalancer` in `services/desk-gateway/src/desk_gateway/workload.py` (REQ-CHAOS-003):
   - Detect unacknowledged task graph workloads on unresponsive or isolated seats.
   - Redistribute pending tasks to compatible healthy peer seats according to capability matrix (e.g. `systems` -> `infra`, `lead` -> `systems`, etc.).
   - Advance vector clock entries indicating workload reassignment with audit trail.
2. Implement `DLQReplayOrchestrator` in `services/desk-gateway/src/desk_gateway/dlq_replay.py` (REQ-CHAOS-004):
   - Replay queue items from intake DLQ with exponential backoff and randomized jitter.
   - Quarantine poison pills (payloads failing repeatedly past `max_retries` threshold) to separate poison vault without stalling other items.
3. Implement `ResilienceVerifier` in `services/desk-gateway/src/desk_gateway/resilience.py` (REQ-CHAOS-005):
   - Measure Recovery Time Objective (RTO < 3.0s SLA) and Recovery Point Objective (RPO = 0: no lost task state or unacknowledged items) under chaos injection drills.
   - Export verification summary metrics.
4. Integrate endpoints in `services/desk-gateway/src/desk_gateway/server.py`:
   - `POST /v1/workload/rebalance`: Trigger autonomous rebalance of unresponsive seat tasks.
   - `POST /v1/dlq/replay`: Trigger orchestrated DLQ replay.
   - `GET /v1/resilience/verify`: Run resilience drill and report RTO/RPO SLA compliance.
5. Author test suite `services/desk-gateway/tests/test_resilience_recovery.py`:
   - Test workload redistribution upon seat crash.
   - Test DLQ replay with backoff and poison pill quarantine.
   - Test RTO < 3s and RPO = 0 compliance.
6. Verify all test suites and quality gates pass.
</tasks>
