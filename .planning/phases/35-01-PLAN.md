# Plan 35-01: Self-Healing Reconstitution & Immune Memory Attestation

## Goal
Implement autonomous seat reconstitution from attested checkpoint baselines, tamper-evident immune memory ledger recording attack signatures, proactive antibody distribution sharing mitigation heuristics across federated desks, progressive post-quarantine rehabilitation protocol with synthetic benchmark drills, and an end-to-end chaos anomaly injection test suite.

## Requirements Covered
- **REQ-HEAL-006**: Autonomous seat reconstitution engine regenerating clean agent runtime contexts from attested checkpoint baselines.
- **REQ-HEAL-007**: Swarm immune memory ledger recording behavioral attack signatures and quarantine heuristics into a tamper-evident audit chain.
- **REQ-HEAL-008**: Proactive antibody distribution sharing verified attack heuristics and mitigation policies across federated desks.
- **REQ-HEAL-009**: Progressive post-quarantine rehabilitation protocol validating reconstituted seats via synthetic benchmark drills.
- **REQ-HEAL-010**: End-to-end swarm immune defense verification harness and chaos anomaly injection test suite.

## Proposed Architecture & Design
1. **Module `services/desk-gateway/src/desk_gateway/swarm_reconstitution.py`**:
   - `CheckpointBaseline`: Represents a signed golden snapshot containing seat role, baseline capabilities, runtime environment configs, and hash commitment.
   - `ImmuneMemoryEntry` & `ImmuneMemoryLedger`:
     - SHA-256 block-chained entries recording attack heuristics, anomalous payload fingerprints, quarantine reasons, and mitigation actions.
     - Merkle root computation over attack signatures for tamper-evident audit verification.
   - `AntibodyPolicy` & `AntibodyDistributionMesh`:
     - Packages verified attack signatures into distributable "antibody rules" (e.g. payload regexes, entropy caps, latency anomaly bounds).
     - Signed distribution packets with HMAC-SHA256 for federated desk ingestion.
     - Local antibody enforcement filter rejecting matching patterns before tool execution.
   - `ProgressiveRehabilitationEngine`:
     - Multi-stage rehabilitation drill pipeline (`RECONSTITUTING` -> `SYNTHETIC_BENCHMARK` -> `SHADOW_MONITORING` -> `GRADUATED_HEALTHY`).
     - Synthetic challenge evaluation: runs controlled probe tasks to measure baseline conformity.
   - `SwarmReconstitutionEngine`:
     - Coordinates clean context regeneration: resets quarantined/drained seats to golden baselines, updates capability manifests, records to immune memory ledger, generates antibodies, and executes the progressive rehabilitation protocol.
   - `ChaosAnomalyHarness`:
     - Anomaly injection suite simulating entropy surges, Byzantine tool failures, prompt injection signatures, and latency poisoning to verify autonomous self-healing.

2. **REST Endpoints in `services/desk-gateway/src/desk_gateway/server.py`**:
   - `POST /v1/immune/reconstitute`: Trigger autonomous reconstitution of a quarantined/drained seat.
   - `GET /v1/immune/memory/ledger`: Retrieve chain of immune memory blocks and Merkle root.
   - `POST /v1/immune/antibodies/broadcast`: Export signed antibody package.
   - `POST /v1/immune/antibodies/ingest`: Ingest federated antibody package and apply active mitigation filters.
   - `POST /v1/immune/rehabilitate/benchmark`: Execute progressive rehabilitation synthetic benchmark drill for a reconstituted seat.
   - `POST /v1/immune/chaos/inject`: Chaos anomaly injection verification drill.

3. **Verification**:
   - Unit and integration tests in `services/desk-gateway/tests/test_swarm_reconstitution.py`.
   - Quality gates: `check_ownership.py --validate-manifest`, `check_secrets.py`, `check_desk_integrity.py`.
   - Overall gateway test suite passing.
