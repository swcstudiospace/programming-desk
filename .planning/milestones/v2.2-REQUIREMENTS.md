# Requirements: Milestone v2.2 — Multi-Desk Federation & Staging Deployments

This document defines the requirements for Milestone v2.2 of Programming Desk.

## 1. Multi-Desk Federation & Inter-Seat Routing (Phase 10)

- [x] **REQ-FED-001**: Inter-desk gateway protocol allowing multiple Programming Desk instances to peer and exchange ticket assignments securely.
- [x] **REQ-FED-002**: Federated token authentication supporting multi-tenant JWT validation with rotating public keys.
- [x] **REQ-FED-003**: Cross-desk role negotiation ensuring seat boundaries (LEAD, SYSTEMS, WEB, etc.) remain intact across federated peers.
- [x] **REQ-FED-004**: Multi-desk task graph synchronization with conflict resolution and state convergence.
- [x] **REQ-FED-005**: Federated circuit breaking and fail-open routing for peer desk partitions.

## 2. Automated Staging & VPS Environment Promotion (Phase 11)

- [x] **REQ-STAGE-001**: Declarative VPS deployment pipeline with automated rollback triggering on health/gate regression.
- [x] **REQ-STAGE-002**: Automated zero-downtime hot-reloading for Desk Gateway instances behind Nginx TLS termination.
- [x] **REQ-STAGE-003**: Production/staging environment lease reconciliation and automated pruning for ephemeral test branches.
- [x] **REQ-STAGE-004**: Integration harness validating end-to-end webhook-to-PR-merge promotion in isolated staging runners.
- [x] **REQ-STAGE-005**: Automated cross-repo synchronization verification with `agent-substrate` and `agent-swarm`.
