# Plan 17-01: Inter-Desk Agent Mesh & Distributed Work Distribution

## Objective
Implement inter-desk agent service discovery protocol, asynchronous inter-desk RPC protocol via VPS Agent Bus, cross-organization receipt co-signing protocol, decentralized task delegation state machine, and continuous verification test suite across autonomous desk instances (`REQ-MESH-001` through `REQ-MESH-005`).

## Requirements
- `REQ-MESH-001`: Inter-desk agent service discovery protocol registering autonomous desk instances (Programming, Recruitment, Trading) over Tailnet mesh.
- `REQ-MESH-002`: Asynchronous inter-desk RPC protocol via VPS Agent Bus enabling cross-desk task handoffs and progress tracking.
- `REQ-MESH-003`: Cross-organization receipt co-signing protocol verifying multi-agent task completion with dual-party cryptographic attestation.
- `REQ-MESH-004`: Decentralized task delegation state machine handling timeout negotiation, delegation rejection, and automated recall to originating desk.
- `REQ-MESH-005`: Continuous inter-desk mesh verification test suite validating end-to-end multi-desk ticket lifecycle and receipt reconciliation.

## Proposed Components
1. `desk_gateway.mesh`:
   - `DeskType` enum: `PROGRAMMING`, `RECRUITMENT`, `TRADING`, `CUSTOM`.
   - `MeshDeskNode`: Identity, tailnet endpoint, desk type, public keys, health and capabilities.
   - `MeshDiscoveryRegistry`: Registry for advertising, registering, heartbeating, and resolving autonomous desk nodes over Tailnet mesh (`REQ-MESH-001`).
   - `AgentBusMessage`, `AgentBusRPC`: Asynchronous inter-desk message bus protocol with correlation IDs, progress callback tracking, and async task handoff (`REQ-MESH-002`).
   - `CoSignedReceipt`, `ReceiptCoSigner`: Dual-party cryptographic HMAC-SHA256 attestation verifying multi-agent task completion across desks (`REQ-MESH-003`).
   - `DelegationState` enum and `DelegatedTaskStateMachine`: States (`INITIATED`, `ACCEPTED`, `IN_PROGRESS`, `REJECTED`, `TIMED_OUT`, `RECALLED`, `COMPLETED`), timeout negotiation, rejection handling, and automated recall to originating desk (`REQ-MESH-004`).
2. Gateway Integration (`desk_gateway.server`):
   - Expose REST endpoints:
     - `POST /v1/mesh/register` & `GET /v1/mesh/desks` (`REQ-MESH-001`)
     - `POST /v1/mesh/rpc/dispatch` & `GET /v1/mesh/rpc/tasks/{task_id}` (`REQ-MESH-002`)
     - `POST /v1/mesh/receipts/cosign` & `POST /v1/mesh/receipts/verify` (`REQ-MESH-003`)
     - `POST /v1/mesh/delegation/advance` & `POST /v1/mesh/delegation/recall` (`REQ-MESH-004`)
     - `GET /v1/mesh/verify` (`REQ-MESH-005`)
3. Test Suite:
   - `services/desk-gateway/tests/test_inter_desk_mesh.py`: Full verification of all 5 mesh requirements.
