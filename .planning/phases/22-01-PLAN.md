# Plan 22-01: Dynamic Seat Load Balancing & Swarm Backpressure Management

**Milestone:** v2.8 - Autonomous Swarm Self-Balancing & Work Distribution Mesh  
**Phase:** 22 - Dynamic Seat Load Balancing & Swarm Backpressure Management  
**Requirements:** `REQ-SWARM-001`, `REQ-SWARM-002`, `REQ-SWARM-003`, `REQ-SWARM-004`, `REQ-SWARM-005`

## Goal
Implement a dynamic seat load balancing and swarm backpressure management engine in `desk-gateway`:
1. Real-time seat concurrency & workload telemetry tracking (`REQ-SWARM-001`).
2. Dynamic task re-queuing and backpressure spillover routing when target seat is at capacity (`REQ-SWARM-002`).
3. Priority preemption for critical path leadership and security tasks (`REQ-SWARM-003`).
4. Latency-aware and capacity-weighted seat selection across local and federated desks (`REQ-SWARM-004`).
5. Automated worker health circuit breaker with fail-fast fallback routing (`REQ-SWARM-005`).

## Implementation Tasks
1. **Module `services/desk-gateway/src/desk_gateway/swarm_balancer.py`**:
   - `SeatLoadStatus`: Dataclass tracking active jobs, queue depth, max concurrency, latency ms, health status, and failure count.
   - `TaskPriority`: Enum (`LOW`, `NORMAL`, `HIGH`, `CRITICAL`).
   - `SwarmTaskAssignment`: Model representing a swarm task dispatch.
   - `SwarmSeatLoadBalancer`:
     - `record_heartbeat_and_load(seat_id, active_jobs, latency_ms, status)`
     - `dispatch_task(task: SwarmTaskAssignment) -> Dict[str, Any]`
     - Priority preemption: `CRITICAL` or `HIGH` tasks preempt or route immediately.
     - Backpressure spillover: If target seat is full, redirect to available eligible seat or spillover queue.
     - Circuit breaker: Trip seat to `DEGRADED` or `OPEN` if consecutive failures exceed threshold; route tasks to fallback seats.
2. **Gateway Endpoints in `server.py`**:
   - `POST /v1/swarm/telemetry`: Update seat load telemetry.
   - `POST /v1/swarm/dispatch`: Dispatch task through balancer with priority & spillover logic.
   - `GET /v1/swarm/status`: Get aggregate swarm load, queue depths, and circuit breaker states.
   - `POST /v1/swarm/reset-breaker`: Reset tripped breaker for a seat.
3. **Tests & Verification**:
   - `services/desk-gateway/tests/test_swarm_balancer.py`:
     - Test telemetry recording and seat capacity limits.
     - Test backpressure spillover when concurrency exceeds max limit.
     - Test priority preemption for `CRITICAL` tasks.
     - Test latency-weighted seat routing across peers.
     - Test circuit breaker tripping and failover routing.
     - Test Starlette TestClient API endpoints.
4. **Gates**:
   - G-1 through G-7 clean.
