<objective>
Implement a synthetic chaos injection harness simulating intermittent upstream network partitions, packet loss, and latency spikes across Railway dependencies (GreptimeDB, TimescaleDB, DragonflyDB, Hindsight, RAGFlow), alongside an automated self-healing supervisor detecting corrupted or partitioned seat instances and triggering zero-downtime hot reconstitution (REQ-CHAOS-001, REQ-CHAOS-002).

Output: New `desk_gateway.chaos` and `desk_gateway.supervisor` modules, chaos injection & supervisor endpoints in `desk_gateway.server`, and comprehensive tests in `tests/test_chaos_recovery.py`.
</objective>

<tasks>
1. Implement `ChaosHarness` in `services/desk-gateway/src/desk_gateway/chaos.py`:
   - Configurable fault injection rules: latency spike (delay ms), packet drop / error rate (pct), network partition (simulated connection refusal or timeout).
   - Targetable upstreams: greptime, timescale, dragonfly, hindsight, ragflow, or all.
   - Dynamic injection scheduling: duration, probability, active fault inspection, and automated expiration/cleanup.
2. Implement `SelfHealingSupervisor` in `services/desk-gateway/src/desk_gateway/supervisor.py`:
   - Real-time seat integrity & liveness tracking (heartbeat monitoring, corruption/anomaly detection, partition state).
   - Zero-downtime hot reconstitution: recycling seat state, resetting token buckets, restoring rosters, and transparently reconstituting failed seat instances without restarting the gateway process.
   - Coordination with `EmergencyIsolationManager` and `FailoverRouter` for automated quarantine-to-reconstitution recovery pipelines.
3. Wire chaos harness and self-healing supervisor into `services/desk-gateway/src/desk_gateway/server.py`:
   - Endpoints: `GET /v1/chaos/rules`, `POST /v1/chaos/inject`, `POST /v1/chaos/reset` (restricted to lead/infra/systems).
   - Endpoints: `GET /v1/supervisor/seats`, `POST /v1/supervisor/reconstitute` (zero-downtime hot reconstitution).
   - Intercept upstream health checks with active chaos rules.
4. Author test suite `services/desk-gateway/tests/test_chaos_recovery.py` verifying:
   - Upstream fault injection (latency, drops, partitions).
   - Self-healing supervisor detecting corrupted/failing seats and executing zero-downtime reconstitution.
   - Quality gates G-1, G-2, G-3, G-4, and G-7 verification.
5. Verify all tests pass.
</tasks>
