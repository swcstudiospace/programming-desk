# Plan 20-01: Artifact Ingestion Pipeline, Content Inspection, & Streaming Tool Execution Bus

**Milestone:** v2.7 — Multi-Modal Processing & Streaming Tool Execution  
**Phase:** 20 — Multi-Modal Artifact Ingestion & Streaming Tool Execution  
**Requirements:** `REQ-MM-001`, `REQ-MM-002`, `REQ-MM-003`

## Goal
Implement a multi-modal artifact ingestion pipeline and streaming tool execution bus in `desk-gateway` with support for:
1. Multi-modal artifact ingestion handling image, audio, document, and binary payloads with magic byte MIME inspection, SHA-256 payload digests, and security validation (`REQ-MM-001`).
2. Streaming tool execution bus enabling chunked Server-Sent Events (SSE) and chunk frames from tools/MCP servers with intermediate telemetry progress frames (`REQ-MM-002`).
3. Execution cancellation and backpressure supervisor supporting mid-stream client disconnects, timeouts, and resource reclamation (`REQ-MM-003`).

## Implementation Tasks

1. **Multi-Modal Artifact Module (`services/desk-gateway/src/desk_gateway/multimodal.py`)**:
   - `ArtifactType`: Enum (`IMAGE`, `AUDIO`, `DOCUMENT`, `VIDEO`, `BINARY`).
   - `ArtifactMetadata`: Model capturing artifact ID, MIME type, size bytes, SHA-256 digest, width/height (for images), duration seconds (for audio), tenant ID, seat ID, timestamp.
   - `MultiModalArtifactPipeline`: Validates byte headers (magic bytes for PNG, JPEG, WEBP, GIF, WAV, MP3, PDF), rejects dangerous files (executable/script detection), extracts metadata, stores payload reference or in-memory buffer.
   - `StreamingFrameType`: Enum (`START`, `CHUNK`, `TELEMETRY`, `ERROR`, `COMPLETE`, `CANCELLED`).
   - `StreamingFrame`: Model capturing stream ID, frame sequence, frame type, tool name, payload, elapsed ms, timestamp.
   - `StreamingToolBus`: Pub/sub and async generator stream orchestrator that receives tool chunks and emits structured SSE / frame objects with backpressure queues.
   - `StreamCancellationSupervisor`: Tracks active streams, handles client disconnect signals, cancels underlying async tasks, and triggers cleanup callbacks.

2. **API Endpoints in `services/desk-gateway/src/desk_gateway/api.py`**:
   - `POST /v1/multimodal/ingest`: Ingest binary/image/audio payload or base64 metadata, return registered `ArtifactMetadata`.
   - `GET /v1/multimodal/artifacts/{artifact_id}`: Retrieve artifact metadata and status.
   - `POST /v1/tools/streaming/execute`: Launch streaming tool execution yielding `StreamingFrame` stream (or SSE response).
   - `POST /v1/tools/streaming/{stream_id}/cancel`: Cancel active tool execution stream with immediate resource cleanup.
   - `GET /v1/tools/streaming/{stream_id}/status`: Inspect status of active or completed stream.

3. **Unit & Integration Tests**:
   - Add `services/desk-gateway/tests/test_multimodal.py` covering:
     - Valid artifact ingestion for PNG, JPEG, WAV, PDF.
     - Rejection of invalid magic bytes or disallowed MIME types.
     - Streaming tool execution emitting `START`, `CHUNK`, `TELEMETRY`, `COMPLETE`.
     - Mid-stream cancellation by supervisor and queue clearance.
     - HTTP API endpoints in FastAPI.

4. **Quality Gates & PR**:
   - Ensure gates G-1 through G-7 pass.
   - Run full gateway test suite.
