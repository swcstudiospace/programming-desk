# grokbot/

What the desk needs in order to be installed on Grok Bot for a team. Owner: LEAD
(`ownership.yaml`, `grokbot/**`). Plan of record: `docs/upgrade-plan-desk-v2.md` §8.1, §9.

| Path | What it is |
|---|---|
| `rosters/<team>.json` | One roster per team: the desk channel id, the seven seat UUIDs, the gateway URL and a `roster_version`. `scripts/assemble-prompts.sh --roster` reads it to fill `{{DESK_CHANNEL_ID}}`, `{{SEAT_UUID:<SEAT>}}`, `{{DESK_GATEWAY_URL}}` and `{{DESK_ROSTER_VERSION}}` in the prompt sources. |
| `templates/<SEAT>.md` | The seven Grok Bot Team-only templates (name, description, enabled skills, routines, avatar). Generated by `scripts/generate-templates.py` from the seat prompts and `contracts/tool-rosters/`. Never hand-edited; regenerate instead. |
| `avatars/` | Seat avatars, `<short>.png` (`lead.png` … `quality.png`). Placeholder until the images are added. |

## Ids are not secrets

Agent UUIDs and the channel id are addressing, not credentials: they identify a Bot, they do not
authenticate one. That is why `rosters/spectrumwebco.json` is committed. Tokens, passphrases,
tailnet names and `railway.internal` hosts never go in this directory; G-7
(`ci/gates/check_desk_integrity.py`) fails a template that contains a token shape, a tailnet name
or a literal UUID.

## Another team's roster

A recipient team does not write a roster by hand. Each of its Bots runs `/desk bootstrap`
(`skills/desk-bootstrap`), which calls `desk_doctor register` on the gateway; the gateway records
`seat -> uuid` and, from LEAD, the channel id. Once `desk_roster_status` shows seven registrations
and a channel id, the gateway holds that team's roster and `desk_doctor install_prompt` renders
the assembled prompt from it. A copy under `rosters/<team>.json` is only needed when the prompts
are assembled outside the gateway (CI, a local check).

## Regenerate

```bash
bash scripts/assemble-prompts.sh              # prompts-assembled/*.xml from the default roster
bash scripts/assemble-prompts.sh --check      # CI: fail on drift
python3 scripts/generate-templates.py         # grokbot/templates/*.md
python3 ci/gates/check_desk_integrity.py      # G-7
```
