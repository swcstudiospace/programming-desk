# Plan 37-01: Autonomous Prompt Optimization & Self-Refining Instruction Loops

## Objective
Implement telemetry-driven prompt evaluation, genetic prompt mutation, shadow A/B canary testing, cryptographic prompt rollout with SHA-256 lineage tracking, and regression benchmarking.

## Components to Deliver
1. `services/desk-gateway/src/desk_gateway/prompt_optimizer.py`:
   - `PromptVariant`: Encapsulates prompt text, revision ID, seat ID, parent revision ID, generation depth, and metadata.
   - `PromptTelemetryEvaluator`: Scores prompt runs on task success, tool call accuracy, latency, and token consumption.
   - `EvolutionaryPromptEngine`: Genetic mutation loop perturbing instructions (instruction restructuring, few-shot conditioning, constraint sharpening, role emphasis).
   - `CanaryBenchmarkHarness`: Shadow A/B evaluator comparing incumbent vs candidate variants against a golden prompt evaluation dataset.
   - `PromptRolloutOrchestrator`: Manages cryptographic signing, version lineage, canary stage advancement, atomic promotion, and instant rollbacks.
2. Gateway Integration in `services/desk-gateway/src/desk_gateway/server.py`:
   - Routes for candidate mutation, canary scoring, promotion, rollback, and version lineage audit.
3. Unit & Integration Test Suite in `services/desk-gateway/tests/test_prompt_optimizer.py` and `test_prompt_optimizer_gateway.py`:
   - Full coverage for evolutionary operators, fitness scoring, canary promotion thresholds, and rollback idempotency.
