# Plan 29-01: Cross-Desk Distributed Remote Tool Invocation & Attested Execution Receipts

## Objective
Implement Phase 29 requirements (`REQ-MCP-006` through `REQ-MCP-010`) to deliver secure cross-desk remote tool execution with cryptographic attestations, streaming output, timeout supervision, and audit logging.

## Requirements Covered
- `REQ-MCP-006`: Asynchronous RPC transport for cross-desk tool invocations over private WAN mesh.
- `REQ-MCP-007`: Cryptographic request-response signing with seat identity attestation.
- `REQ-MCP-008`: Streaming execution proxy supporting real-time progress and telemetry relay.
- `REQ-MCP-009`: Distributed tool execution timeout supervision and zombie process reclamation.
- `REQ-MCP-010`: Non-repudiable tool execution receipts with input/output content hashing and audit logging.

## Implementation Architecture
1. **Module `services/desk-gateway/src/desk_gateway/mcp_remote_invoker.py`**:
   - `ExecutionReceipt`: Data class containing `invocation_id`, `tool_name`, `source_seat`, `target_server_id`, `input_hash`, `output_hash`, `status`, `duration_ms`, `timestamp`, and `signature`.
   - `RemoteInvocationRequest`: Request structure with attestation token and signed payload.
   - `StreamingProgressChunk`: Chunk for telemetry / streaming tool progress events.
   - `MCPRemoteExecutionSupervisor`:
     - Asynchronous tool invocation runner with configurable timeout enforcement.
     - Integration with `DynamicMCPToolMeshRegistry` for slot acquisition / release and circuit state.
     - Cryptographic signing using seat private keys or gateway HMAC / Ed25519 signatures.
     - Streaming generator / queue dispatch for tool progress chunks.
     - Execution receipt generation with SHA256 input/output hashing and verification.
     - Timeout cancellation and resource cleanup.
2. **Gateway Endpoints (`services/desk-gateway/src/desk_gateway/server.py`)**:
   - `POST /v1/mcp-mesh/invoke`: Asynchronous tool execution with attested signing and receipt creation.
   - `GET /v1/mcp-mesh/receipts/{invocation_id}`: Query stored tool execution receipt.
   - `POST /v1/mcp-mesh/receipts/verify`: Cryptographically verify execution receipt signature and hash integrity.
   - Expose `remote_execution_supervisor` in `app.state["components"]`.
3. **Tests (`services/desk-gateway/tests/test_mcp_remote_invoker.py`)**:
   - Asynchronous remote invocation and success path.
   - Attested signing and cryptographic verification of receipts.
   - Input and output SHA256 hashing.
   - Timeout supervision and cancellation.
   - Gateway endpoints via `TestClient`.
