# Plan 23-01: Autonomous Hierarchical Subagent Delegation & Byzantine Consensus Receipts

**Milestone:** v2.8 - Autonomous Swarm Self-Balancing & Work Distribution Mesh  
**Phase:** 23 - Autonomous Hierarchical Subagent Delegation & Byzantine Consensus Receipts  
**Requirements:** `REQ-SWARM-006`, `REQ-SWARM-007`, `REQ-SWARM-008`, `REQ-SWARM-009`, `REQ-SWARM-010`

## Goal
Implement a decentralized, cryptographically evidenced hierarchical delegation protocol in `desk-gateway` with support for:
1. Recursive subagent task decomposition and delegation protocol supporting nested parent-child task DAGs (`REQ-SWARM-006`).
2. Cryptographic task handoff and acceptance receipts with timestamped nonces and task fingerprinting (`REQ-SWARM-007`).
3. Dual-party signature verification for cross-seat delegation acknowledging receipt before execution state transitions (`REQ-SWARM-008`).
4. Byzantine dispute arbitration and timeout reclamation engine handling unresponsive or conflicting subagent claims (`REQ-SWARM-009`).
5. End-to-end swarm execution audit receipt aggregation validating hierarchical delegation integrity and non-repudiation (`REQ-SWARM-010`).

## Implementation Tasks
1. **Module `services/desk-gateway/src/desk_gateway/swarm_delegation.py`**:
   - `DelegationState`: Enum (`OFFERED`, `ACCEPTED`, `IN_PROGRESS`, `COMPLETED`, `DISPUTED`, `RECLAIMED`).
   - `DelegationReceipt`: Dataclass capturing task ID, parent task ID, delegator seat, delegatee seat, task fingerprint, timestamp, nonce, delegator signature, and delegatee signature.
   - `HierarchicalTaskNode`: Dataclass tracking task graph nodes, parent-child relationships, subtasks, depth ceiling, and execution receipts.
   - `SwarmDelegationMesh`:
     - Recursive task decomposition (`create_subtask`, depth check ≤ 5).
     - Two-phase handoff: `offer_delegation` + `accept_delegation` (dual-party HMAC signature generation & verification).
     - Dispute arbitration: `raise_dispute(task_id, reason)` + `arbitrate_dispute(task_id, ruling)`.
     - Timeout reclamation: `reclaim_timed_out_tasks(timeout_seconds)`.
     - Aggregate audit proof: `generate_tree_audit_receipt(root_task_id) -> Dict[str, Any]` with Merkle digest calculation over all child receipts.
2. **Gateway Endpoints in `server.py`**:
   - `POST /v1/swarm/delegation/offer`: Offer subtask delegation to target seat.
   - `POST /v1/swarm/delegation/accept`: Accept delegation and supply delegatee signature.
   - `POST /v1/swarm/delegation/complete`: Complete delegated task.
   - `POST /v1/swarm/delegation/dispute`: Raise Byzantine dispute.
   - `POST /v1/swarm/delegation/reclaim`: Trigger timeout reclamation.
   - `GET /v1/swarm/delegation/audit/{root_task_id}`: Fetch aggregated tree audit receipt.
3. **Tests & Verification**:
   - Add `services/desk-gateway/tests/test_swarm_delegation.py`:
     - Test parent-child DAG creation and recursion limits.
     - Test cryptographic task fingerprinting, dual signatures, and acceptance validation.
     - Test rejection of invalid signatures.
     - Test dispute arbitration and timeout reclamation.
     - Test tree audit aggregation with Merkle root verification.
     - Test FastAPI/Starlette test client endpoints.
4. **Gates**:
   - G-1 through G-7 clean.
