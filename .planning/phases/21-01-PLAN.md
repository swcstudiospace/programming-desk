# Plan 21-01: Bi-Directional Streaming RPC & Distributed Media Cache

**Milestone:** v2.7 — Multi-Modal Processing & Streaming Tool Execution  
**Phase:** 21 — Dynamic Streaming Tool Mesh & Real-Time Telemetry  
**Requirements:** `REQ-STREAM-001`, `REQ-STREAM-002`

## Goal
Implement bi-directional streaming RPC transport between federated desks with heartbeat keepalive and flow control (`REQ-STREAM-001`), along with a distributed multi-modal media cache synchronized across edge nodes with cryptographic content hashing and LRU eviction (`REQ-STREAM-002`).

## Implementation Tasks

1. **Bi-Directional Streaming RPC (`services/desk-gateway/src/desk_gateway/streaming_mesh.py`)**:
   - `StreamRPCFrameType`: Enum (`HANDSHAKE`, `HEARTBEAT`, `HEARTBEAT_ACK`, `DATA`, `ACK`, `WINDOW_UPDATE`, `CLOSE`, `ERROR`).
   - `StreamRPCFrame`: Frame container with sequence, session ID, ACK sequence, window credit, payload, and timestamps.
   - `StreamingMeshRPC`: Sliding window flow control, backpressure prevention, session keepalive, and timeout enforcement.

2. **Distributed Media Cache (`services/desk-gateway/src/desk_gateway/streaming_mesh.py`)**:
   - `MediaCacheEntry`: Content hash (SHA-256), payload, size, MIME type, tenant ID, sync origins, access timestamps.
   - `DistributedMediaCache`: Content-addressed storage with LRU eviction on byte limits or entry capacity, tamper verification on edge synchronization.

3. **Gateway Server Endpoints & Integration (`services/desk-gateway/src/desk_gateway/server.py`)**:
   - `POST /v1/mesh/streaming/session/open`: Open bi-directional streaming RPC session.
   - `POST /v1/mesh/streaming/frame/send`: Send data frames governed by sliding window credit.
   - `POST /v1/mesh/streaming/cache/put`: Store media payloads keyed by cryptographic SHA-256.
   - `GET /v1/mesh/streaming/cache/get/{content_hash}`: Retrieve media cache entry.

4. **Testing (`services/desk-gateway/tests/test_streaming_mesh.py`)**:
   - Test handshake and flow control exhaustion with window replenishment via ACKs.
   - Test heartbeat keepalive and timeout expiry.
   - Test cryptographic cache storage and LRU eviction under byte ceilings.
   - Test edge sync with cryptographic hash tamper detection.
