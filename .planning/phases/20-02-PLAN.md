# Plan 20-02: Multi-Modal Sensory Memory Indexing & Streaming Verification Harness

**Milestone:** v2.7 — Multi-Modal Processing & Streaming Tool Execution  
**Phase:** 20 — Multi-Modal Artifact Ingestion & Streaming Tool Execution  
**Requirements:** `REQ-MM-004`, `REQ-MM-005`

## Goal
Implement sensory memory indexing and verification harness in `desk-gateway`:
1. Multi-modal sensory memory indexer storing and querying multi-modal vector embeddings linked to desk ledger transactions and artifacts (`REQ-MM-004`).
2. Streaming verification harness validating chunk delivery latencies (<20ms per frame), RPO=0 audit compliance, and resource cleanup under sudden connection aborts (`REQ-MM-005`).

## Implementation Tasks

1. **Sensory Memory Indexing (`services/desk-gateway/src/desk_gateway/multimodal_memory.py`)**:
   - `SensoryMemoryRecord`: Dataclass capturing memory ID, artifact ID, tenant ID, seat ID, embedding vector (normalized float list), dimensions, modality, transcription/caption, ledger ref, and timestamp.
   - `cosine_similarity(vec_a, vec_b)`: Computes normalized cosine similarity between vectors.
   - `SensoryMemoryIndexer`: In-memory / vector index supporting insertion, top-k similarity search with modality filters, tenant isolation, and linking to desk ledger transaction vouchers.
   - `MultiModalStreamingVerifier`: Verification harness running synthetic high-frequency streaming workloads, asserting sub-20ms frame latencies, graceful cancellation, zero orphaned resources, and RPO=0 ledger consistency.

2. **Integration into MCP Gateway Server (`services/desk-gateway/src/desk_gateway/server.py`)**:
   - Instantiate `SensoryMemoryIndexer` and `MultiModalStreamingVerifier`.
   - Expose endpoints:
     - `POST /v1/multimodal/memory/index`: Index multi-modal memory embedding.
     - `POST /v1/multimodal/memory/search`: Query nearest neighbor sensory memories with score threshold.
     - `POST /v1/multimodal/streaming/verify`: Run end-to-end streaming latency & RPO=0 verification suite.

3. **Unit & Integration Tests (`services/desk-gateway/tests/test_multimodal_memory.py`)**:
   - Test cosine similarity and top-k search with modality filters.
   - Test sensory memory linking with artifact metadata and ledger vouchers.
   - Test verification harness assertions (<20ms per frame, cancellation, RPO=0).
   - Test HTTP endpoints via Starlette `TestClient`.

4. **Phase 20 Completion & Milestone Tracking**:
   - Mark `REQ-MM-004` and `REQ-MM-005` complete in `.planning/REQUIREMENTS.md`.
   - Update `.planning/ROADMAP.md` and `.planning/STATE.md`.
   - Run gates G-1 to G-7 and pytest test suites.
