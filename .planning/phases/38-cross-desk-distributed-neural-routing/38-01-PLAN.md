# Phase 38 Plan 01: Cross-Desk Distributed Neural Routing & Semantic Dispatch

## Context & Objective
Implement distributed neural routing across federated desks and seats. Incoming tasks are vectorized across semantic taxonomy, complexity, required tools, and domain parameters. The neural routing policy calculates multi-objective routing scores factoring in capability compatibility, real-time desk capacity, latency curves, and token budget envelopes. Cross-desk context forwarding packages memory, conversation history, and sensory graph embeddings securely. A dynamic circuit breaker maintains desk health status with shadow probes, and routing decisions are cryptographically attested via HMAC-SHA256 receipts.

## Implementation Steps
1. Create `services/desk-gateway/src/desk_gateway/neural_routing.py`:
   - `IntentVectorizer`: Vectorizes task text and capability requirements into multi-dimensional normalized semantic embeddings.
   - `DeskCapabilityProfile`: Represents desk and seat capabilities, domains, supported tools, current load, latency profile, and pricing tier.
   - `NeuralRoutingPolicy`: Multi-objective scoring algorithm computing compatibility, capacity availability, cost efficiency, and latency penalty.
   - `ContextForwardingEnvelope`: Serializes conversation context, session artifacts, and sensory embeddings for transparent cross-desk transfer.
   - `RoutingCircuitBreaker`: Tracks desk link latency, error rates, and failure thresholds with state machine (`HEALTHY`, `DEGRADED`, `OPEN`) and shadow probe heartbeats.
   - `RoutingDecisionReceipt`: HMAC-SHA256 attested receipt recording candidate scores, selected desk/seat, latency estimate, and timestamp.
   - `NeuralRoutingEngine`: Orchestrates vectorization, candidate scoring, circuit-breaker checks, failover fallback, envelope generation, and receipt signing.
2. Integrate into `services/desk-gateway/src/desk_gateway/server.py`:
   - Add routes:
     - `POST /v1/neural-routing/register-desk`
     - `POST /v1/neural-routing/dispatch`
     - `POST /v1/neural-routing/circuit-breaker/probe`
     - `GET /v1/neural-routing/mesh/status`
     - `GET /v1/neural-routing/receipt/{receipt_id}`
3. Implement comprehensive test suite:
   - `services/desk-gateway/tests/test_neural_routing.py`
   - `services/desk-gateway/tests/test_neural_routing_gateway.py`
4. Run quality gates (G-1, G-3, G-7) and pytest suite.
