<objective>
Implement multi-tenant organization/team namespace isolation and an ABAC/RBAC policy engine governing seat tool invocation privileges and data-plane access (REQ-TENANT-001, REQ-TENANT-002).

Output:
- `desk_gateway.tenant`: Multi-tenant isolation engine (`TenantContext`, `TenantIsolationEngine`, `TenantNamespace`).
- `desk_gateway.rbac`: ABAC/RBAC policy engine (`RBACPolicyEngine`, `Role`, `Permission`, `PolicyRule`).
- Integration into `desk_gateway.server` middleware and tool calling pipeline.
- Tests in `services/desk-gateway/tests/test_tenant_governance.py`.
</objective>

<tasks>
1. Implement `TenantContext` & `TenantIsolationEngine` in `services/desk-gateway/src/desk_gateway/tenant.py` (REQ-TENANT-001):
   - Tenant identity representation: `tenant_id`, `org_id`, `team_id`, `environment` (`prod`, `staging`, `dev`).
   - Namespace resolution from HTTP headers (`X-Tenant-Id`, `X-Org-Id`, `X-Team-Id`), bearer tokens, or client certificates.
   - Tenant isolation boundary checks preventing cross-tenant access to seats, rosters, data stores, and memory partitions.
   - Contextvars-based tenant context propagation across asynchronous gateway workflows.
2. Implement `RBACPolicyEngine` in `services/desk-gateway/src/desk_gateway/rbac.py` (REQ-TENANT-002):
   - Role-Based and Attribute-Based Access Control: evaluate caller roles (`admin`, `lead`, `developer`, `operator`, `guest`), seat identities, tool tags (read-only, write, `g5`, `g6`), and resource attributes.
   - Granular permission matrix: `allow`, `deny`, and conditional evaluation based on environment, tenant scope, and ticket approval requirements.
   - Default deny posture with structured rejection explanations.
3. Wire Tenant and RBAC enforcement into `services/desk-gateway/src/desk_gateway/server.py`:
   - Tenant middleware in request pipeline populating `current_tenant` contextvar.
   - Integrate RBAC evaluation in `SeatServer.call_tool` and REST endpoints.
   - REST endpoints: `GET /v1/tenant/current`, `GET /v1/tenant/policies`, `POST /v1/tenant/policies/evaluate`.
4. Author comprehensive test suite `services/desk-gateway/tests/test_tenant_governance.py` verifying:
   - Tenant isolation & cross-tenant access rejection.
   - ABAC/RBAC policy enforcement on tool invocation and administrative actions.
   - Tenant context propagation across asynchronous flows.
5. Verify test pass rate and quality gate checks.
</tasks>
