# Plan 36-01: Dynamic Skill & Tool Synthesis

## Objective
Implement an autonomous skill synthesis and tool generation engine that dynamically generates, validates, tests, hot-reloads, and manages the lifecycle of new agent tools from capability gaps.

## Components to Deliver
1. `services/desk-gateway/src/desk_gateway/skill_synthesis.py`:
   - `SkillSpecification`: Pydantic model defining tool metadata, parameters schema, return type, required permissions, and author seat ID.
   - `ASTSecurityValidator`: Python AST inspector vetting synthesized Python tool code against prohibited imports (e.g. `os`, `subprocess`, `sys`, `shutil`, `socket`), prohibited calls (`eval`, `exec`, `open`, `__import__`), and complexity boundaries.
   - `SyntheticSandboxHarness`: Ephemeral isolated execution runner executing test cases with timeouts, memory limits, and output assertions.
   - `SkillSynthesisEngine`: Orchestrates tool generation, AST verification, sandbox trial execution, HMAC attestation signing, and deployment.
   - `ToolLifecycleManager`: Tracks usage frequency, execution latencies, error rates, and automated deprecation/retirement of degraded tools.
2. Gateway Integration in `services/desk-gateway/src/desk_gateway/server.py`:
   - Endpoints for skill synthesis requests, sandbox testing, registration, invocation, and lifecycle status.
3. Unit & Integration Test Suite in `services/desk-gateway/tests/test_skill_synthesis.py`:
   - Full coverage for valid generation, AST rejection of malicious code, sandbox timeout enforcement, lifecycle metrics, and gateway endpoints.
