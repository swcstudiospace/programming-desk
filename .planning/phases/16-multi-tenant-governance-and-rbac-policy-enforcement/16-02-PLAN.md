<objective>
Implement tenant-scoped memory & document dataset isolation with cryptographic authentication, multi-tenant quota & fair-share rate policing, and immutable per-tenant cryptographic audit hashing with tamper detection (REQ-TENANT-003, REQ-TENANT-004, REQ-TENANT-005).

Output:
- `desk_gateway.tenant`: Extended memory bank and RAGFlow dataset tenant partitioning & token validation.
- `desk_gateway.tenant_quota`: Multi-tenant quota and fair-share burst policer (`TenantQuotaPolicer`, `TenantQuotaLimits`).
- `desk_gateway.tenant_audit`: Cryptographic event chaining, per-tenant Merkle/SHA-256 audit log, and tamper verification (`TenantAuditLogger`).
- Integration into `desk_gateway.server` routes and test additions in `tests/test_tenant_governance.py`.
</objective>

<tasks>
1. Implement tenant-partitioned memory and document dataset isolation in `services/desk-gateway/src/desk_gateway/tenant.py` (REQ-TENANT-003):
   - Secure memory bank partitioning: `tenant_bank_name(tenant, bank)` mapping `pd-<seat>` to `{tenant.org_id}-{tenant.tenant_id}-pd-<seat>`.
   - RAGFlow dataset isolation: verify dataset queries are scoped to the caller's tenant namespace with cryptographic token attestation.
2. Implement `TenantQuotaPolicer` in `services/desk-gateway/src/desk_gateway/tenant_quota.py` (REQ-TENANT-004):
   - Tenant quota metrics: request rate/minute, burst ceiling, max concurrent operations, fair-share scheduling.
   - Throttling with standard HTTP 429 and `X-Tenant-RateLimit-*` headers when tenant bursts are exceeded.
3. Implement `TenantAuditLogger` in `services/desk-gateway/src/desk_gateway/tenant_audit.py` (REQ-TENANT-005):
   - Immutable SHA-256 chained audit events (`prev_hash` chaining per tenant).
   - Tamper detection verification routine validating log integrity across tenant history.
4. Integrate tenant quota and audit endpoints into `services/desk-gateway/src/desk_gateway/server.py`:
   - `GET /v1/tenant/quota`: Check tenant quota usage and limits.
   - `GET /v1/tenant/audit`: Read tenant audit trail.
   - `POST /v1/tenant/audit/verify`: Verify tamper-proof hash chain integrity for tenant.
5. Add unit and integration tests to `services/desk-gateway/tests/test_tenant_governance.py`:
   - Test tenant memory/dataset isolation.
   - Test tenant quota policer & burst ceilings.
   - Test cryptographic audit hash chaining and tamper detection.
6. Verify all test suites and quality gates pass.
</tasks>
