# Plan 21-02: Client Multiplexing, Adaptive Downsampling, & Stream Auditing

**Milestone:** v2.7 — Multi-Modal Processing & Streaming Tool Execution  
**Phase:** 21 — Dynamic Streaming Tool Mesh & Real-Time Telemetry  
**Requirements:** `REQ-STREAM-003`, `REQ-STREAM-004`, `REQ-STREAM-005`

## Goal
Implement client multiplexing with per-seat permission masking (`REQ-STREAM-003`), adaptive compression and downsampling engine based on WAN telemetry (`REQ-STREAM-004`), and end-to-end cryptographic streaming tool audit logger (`REQ-STREAM-005`).

## Implementation Tasks

1. **Client Multiplexing & Permission Masking (`services/desk-gateway/src/desk_gateway/streaming_mesh.py`)**:
   - `StreamingClientMultiplexer`: Multi-subscriber broadcast queue mechanism per stream.
   - Per-seat sensitivity redaction: non-lead seats have sensitive credentials, keys, and internal logs automatically masked (`[REDACTED_PERMISSION_MASK]`).

2. **Adaptive Payload Downsampler (`services/desk-gateway/src/desk_gateway/streaming_mesh.py`)**:
   - `CompressionQuality`: Tiers (`ORIGINAL`, `HIGH`, `BALANCED`, `LOW`, `MINIMAL`).
   - `NetworkConditions`: Real-time bandwidth (kbps) and latency (ms) inputs.
   - Dynamic evaluation and downsampling adapting media payloads to preserve low latency over congested WAN links.

3. **Streaming Tool Audit Logger (`services/desk-gateway/src/desk_gateway/streaming_mesh.py`)**:
   - `StreamAuditReceipt`: Audit record with frame count, bytes transferred, root Merkle-like receipt hash, and HMAC-SHA256 signature.
   - `StreamingToolAuditLogger`: End-to-end receipt generator and cryptographic validator ensuring RPO=0 audit compliance.

4. **Gateway Server Endpoints & Integration (`services/desk-gateway/src/desk_gateway/server.py`)**:
   - `POST /v1/mesh/streaming/downsample`: Downsample media based on WAN conditions.
   - `POST /v1/mesh/streaming/audit/finalize`: Finalize stream execution audit and generate signed receipt.

5. **Testing (`services/desk-gateway/tests/test_streaming_mesh.py`)**:
   - Test subscriber multiplexing with selective masking between lead and member seats.
   - Test adaptive downsampling under high vs degraded WAN telemetry.
   - Test audit receipt generation and HMAC signature verification with tamper checks.
   - Test full gateway API integration.
