# Plan 18-01: Token Consumption Ledger, Model Cost Translation & Spend Circuit-Breaker

## Objective
Implement real-time token tracking across seats, models, and tenants with micro-dollar expenditure translation and graduated spend limits (warning at 80%, soft throttle at 95%, hard circuit-breaker at 100%).

## Scope
1. Implement `TokenLedger` and `ModelTariff` in `services/desk-gateway/src/desk_gateway/finops.py`:
   - Provider tariff catalog (Anthropic Claude 3.5 Sonnet / Haiku, OpenAI GPT-4o / GPT-4o-mini, Grok 2 / Grok 3, DeepSeek Chat / Reasoner) with input/output/cached per-million rates in micro-dollars ($1 = 1,000,000 micro-dollars).
   - Real-time token usage ingestion: record input tokens, output tokens, cached tokens, seat, model, tenant.
   - Micro-dollar calculation and rolling spend aggregation.
2. Implement `SpendCircuitBreaker` in `finops.py`:
   - Graduated status thresholds:
     - < 80%: `NORMAL`
     - >= 80% and < 95%: `WARNING` (alert emitted)
     - >= 95% and < 100%: `THROTTLED` (request delay / soft limit)
     - >= 100%: `TRIPPED` (reject invocation with 402/429 budget exhaustion)
3. Expose Gateway endpoints in `services/desk-gateway/src/desk_gateway/server.py`:
   - `POST /v1/finops/tokens/record`: Ingest token usage event and calculate cost.
   - `GET /v1/finops/spend`: Query current spend, budget limit, and circuit breaker status.
   - `POST /v1/finops/budget`: Set/update tenant or seat budget threshold.
4. Add comprehensive unit and integration tests in `services/desk-gateway/tests/test_finops.py`.
