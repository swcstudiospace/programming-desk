# Phase 31 Plan: Dynamic Context Window Compression & Semantic Pruning

## 1. Overview
Implement the dynamic context window compression and semantic pruning engine for the desk gateway, enabling lossless token compaction, semantic relevance pruning of low-salience tokens while preserving syntactic and code structure, hierarchical summary rollups with cryptographic long-context eviction proofs, dynamic context window adaptation across LLM tiers and budget ceilings, and context fidelity and reconstruction verification suites.

## 2. Requirements Covered
- `REQ-GRAPH-006`: Lossless token compression and context-window compaction pipeline.
- `REQ-GRAPH-007`: Semantic relevance pruning removing low-salience tokens while preserving syntactic validity.
- `REQ-GRAPH-008`: Hierarchical summary rollups and long-context eviction proofs.
- `REQ-GRAPH-009`: Dynamic context window adaptation based on model tier and budget ceilings.
- `REQ-GRAPH-010`: End-to-end context fidelity and reconstruction verification suite.

## 3. Implementation Tasks
1. Create `services/desk-gateway/src/desk_gateway/context_compressor.py`:
   - Data structures: `CompressionTier`, `ContextSegment`, `CompressionReceipt`, `RollupSummary`, `ContextAdaptationProfile`, `ReconstructionVerificationResult`.
   - `LosslessCompactor`:
     - Compresses text/code segments via gzip/zlib encoding with base64 representation, whitespace normalization, repeated sequence deduplication, and lossless restoration.
   - `SemanticPruner`:
     - Token salience evaluator scoring semantic density, keyword importance, structural syntax tokens, and graph reference salience.
     - Prunes low-salience filler, decorative comments, and redundant tokens while preserving syntactic delimiters (brackets, quotes, structural markers).
   - `HierarchicalRollupEngine`:
     - Chunk-based summary trees with multi-level compaction.
     - Cryptographic eviction proofs with SHA-256 Merkle / chained leaf hashes and HMAC signing so evicted context can be verified.
   - `DynamicWindowAdapter`:
     - Context window budget profiles based on LLM tier (`TIER_1_OPUS`, `TIER_2_SONNET`, `TIER_3_HAIKU`) and cost/token ceilings.
     - Automatically selects compression ratio, semantic pruning threshold, and rollup depth to fit the designated token window.
   - `ContextFidelityVerifier`:
     - Reconstruction and fidelity benchmarking measuring token compression ratio, semantic information retention score (Jaccard / semantic keyword overlap), and structural syntax validation.
   - `ContextCompressionEngine`:
     - Integrated orchestrator combining compactor, pruner, rollup engine, window adapter, and fidelity verifier.
2. Expose REST endpoints in `services/desk-gateway/src/desk_gateway/server.py`:
   - `POST /v1/context/compress`
   - `POST /v1/context/prune`
   - `POST /v1/context/rollup`
   - `POST /v1/context/adapt`
   - `POST /v1/context/verify`
3. Add comprehensive tests in `services/desk-gateway/tests/test_context_compressor.py`:
   - Test lossless compaction & decompression roundtrip (`REQ-GRAPH-006`).
   - Test semantic relevance pruning preserving syntax and brackets (`REQ-GRAPH-007`).
   - Test hierarchical summary rollups and eviction receipts verification (`REQ-GRAPH-008`).
   - Test tier-based dynamic context window adaptation (`REQ-GRAPH-009`).
   - Test context fidelity verification suite (`REQ-GRAPH-010`).
   - Test Starlette HTTP endpoints on `desk-gateway`.
4. Validate quality gates (G-1, G-3, G-7) and pytest.
